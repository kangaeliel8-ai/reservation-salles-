# Réservation de Salles

## Description

Application Java console de gestion des réservations de salles universitaires.
Projet réalisé dans le cadre du module GL3B 2026-2027 (ISM).

## Objectif

Ce projet met en pratique :

- le versionnement avec Git et GitFlow simplifié
- la gestion de build avec Maven
- les concepts fondamentaux de la programmation orientée objet (POO)

## Technologies

- Java 21
- Maven

## Structure du projet

## Domaine métier

- **Salle** : représente une salle réservable
- **Reservation** : représente une réservation effectuée sur une salle
- Une salle peut recevoir plusieurs réservations (1 -- 0..*)

## Versionnement

Ce projet suit une stratégie Semantic Versioning (MAJOR.MINOR.PATCH) :

- v0.1.0 : outillage Git et Maven initialisés
- v0.2.0 : modèle objet du domaine terminé
- v0.3.0 : premières données en mémoire disponibles
